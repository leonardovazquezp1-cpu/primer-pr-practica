# primer-pr-practica

Repositorio de práctica para mi primer Pull Request.

## ¿Qué es esto?

Este repositorio existe para aprender el flujo completo de contribución en GitHub:
crear una rama, hacer un cambio, subirlo y abrir un Pull Request.

## Cómo se hizo este cambio

1. Se creó una rama nueva a partir de `main`.
2. Se editó este `README.md` para agregar más contexto.
3. Se subió la rama al repositorio remoto.
4. Se abrió un Pull Request para fusionar el cambio en `main`.
